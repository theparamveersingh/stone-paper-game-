# 🪨 Stone • Paper • Scissor

A simple and fun **Stone Paper Scissor** game made with Python and Tkinter.

I started with a small console version of the game and turned it into a desktop GUI with a cleaner look, buttons, and a live scoreboard.

## 🎮 Features

- Play against the computer
- Simple and attractive desktop interface
- Live score for:
  - You
  - Computer
  - Draws
- Reset score button
- Random computer moves
- No external Python packages required

## 🛠️ Built With

- Python
- Tkinter
- Random module

## ▶️ How to Run

Make sure Python is installed on your computer.

### Windows

Just double-click:

```text
run_game.bat
```

Or run it from the terminal:

```bash
python game.py
```

## 🕹️ How to Play

Choose **Stone**, **Paper**, or **Scissor**.

The computer randomly chooses its move and the game immediately shows the result.

The scoreboard keeps track of your wins, the computer's wins, and draws until you reset it.

## 📌 Original Game Logic

The game is based on the basic rules:

- Stone beats Scissor
- Paper beats Stone
- Scissor beats Paper
- Same choice = Draw
